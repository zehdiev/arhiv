# Архивът на рафта

Лента с интересни факти от списанията у дома. Скролваш надолу като в Polymath, отбелязваш любими, филтрираш по списание, брой и тема.

## Файлове

| Файл | Какво е |
|---|---|
| `index.html` | Самото приложение |
| `data.json` | Всички списания, броеве и факти |
| `manifest.webmanifest`, `icon-*.png`, `icon.svg` | За инсталиране на телефона като приложение |
| `sw.js` | Работа без интернет |
| `.nojekyll` | Казва на GitHub Pages да не обработва файловете |

Любимите и прочетените факти се пазят в браузъра на всяко устройство поотделно.

## Как се добавя нов брой

1. В `data.json`, в `issues`, се добавя броят:

```json
"ng-2005-03": { "magazine": "National Geographic", "label": "Март 2005", "year": 2005, "month": 3 }
```

2. В `facts` се добавят фактите му:

```json
{
  "id": "ng2005-03-01",
  "issue": "ng-2005-03",
  "magazine": "National Geographic",
  "topic": "animals",
  "kind": "Статия",
  "title": "Кратко заглавие",
  "text": "2–4 изречения.",
  "article": "Заглавие на статията",
  "page": "42"
}
```

Теми (`topic`): `animals`, `nature`, `ocean`, `earth`, `space`, `history`, `people`, `science`, `tech`.

3. Новият `data.json` се качва в GitHub. След минута-две приложението го показва.
